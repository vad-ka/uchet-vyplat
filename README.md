# Учет выплат

Простое веб-приложение для учета денежных выплат получателям с контролем лимита. Один файл `index.html`, без внешних библиотек и без сервера.

Приложение суммирует выплаты по каждому получателю, показывает остаток и процент использования лимита и предупреждает, когда лимит почти или полностью исчерпан.

## Возможности

- Получатели: фамилия и имя обязательны, отчество по желанию.
- Лимит для каждого получателя (необязателен), сумма в рублях. Новый лимит заменяет прежний, история лимитов сохраняется.
- Выплаты: сумма, дата, назначение платежа. Выплату можно внести и сверх лимита, в этом случае показывается предупреждение.
- Итоги: сумма, лимит, остаток.
- Шкала использования лимита с процентом:

| Использование лимита | Цвет шкалы |
|---|---|
| до 80 % включительно | зелёный |
| больше 80 % и меньше 100 % | жёлтый |
| 100 % и больше | красный |

- Отдельная история лимитов и выплат по каждому получателю. Записи можно изменять (✎) и удалять (✕).
- «Сбросить» обнуляет счёт: выплаты остаются в истории как сброшенные и не входят в сумму.
- «Удалить получателя» удаляет его вместе со всей историей.
- Экспорт и импорт данных в файл JSON (резервная копия, перенос на другое устройство).
- Светлая и тёмная тема, выбор запоминается.
- Адаптивная верстка: работает на телефоне и на компьютере.

## Запуск

**Локально.** Скачайте `index.html` и откройте его в браузере двойным щелчком.

**Онлайн через GitHub Pages.**

1. Загрузите `index.html` в корень публичного репозитория.
2. Откройте **Settings → Pages**, в поле Source выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
3. Через несколько минут сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как пользоваться

1. Нажмите «Добавить получателя» и введите фамилию, имя и при желании отчество.
2. При необходимости задайте лимит кнопкой «Установить лимит».
3. Вносите выплаты кнопкой «Выплата».
4. Следите за итогами и шкалой справа.
5. Периодически делайте «Экспорт» для резервной копии.

## Хранение данных и конфиденциальность

- Данные хранятся в `localStorage` вашего браузера (ключ `uchet-vyplat-v1`, тема оформления в ключе `uchet-vyplat-theme`).
- Данные никуда не отправляются: у приложения нет серверной части.
- Каждый пользователь работает только со своими данными на своем устройстве и в своем браузере. Общего доступа к данным нет.
- Данные пропадут при очистке данных сайта в браузере, а в режиме инкогнито не сохраняются после закрытия окна. Для переноса и страховки используйте экспорт и импорт.

## Модель данных

```json
{
  "sel": "id выбранного получателя",
  "list": [
    {
      "id": "…",
      "last": "Иванов",
      "first": "Иван",
      "middle": "Иванович",
      "limits": [{ "id": "…", "amount": 100000, "date": "2026-10-25" }],
      "payments": [
        { "id": "…", "amount": 5000, "date": "2026-10-25", "purpose": "Аванс", "old": false }
      ]
    }
  ]
}
```

Поле `old` помечает выплаты, сброшенные кнопкой «Сбросить».

## Ограничения

- Нет синхронизации между устройствами и совместной работы нескольких пользователей.
- Нет авторизации и ролей.
- Для общего учета потребуется серверная часть с базой данных.

## Технологии

HTML, CSS и JavaScript без зависимостей и сборки.
